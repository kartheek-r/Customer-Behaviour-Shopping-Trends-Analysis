# 🛍️ Customer Behaviour & Shopping Trends Analysis

> An end-to-end data analytics project analyzing customer purchasing behaviour using **SQL**, **Python**, and **Power BI** — from raw data to business insights and interactive dashboards.

---

## 📌 Project Overview

This project simulates a **corporate-grade analytics workflow** to understand customer shopping behaviour and help businesses make data-driven decisions.

The project covers the full analytics pipeline:

| Phase | Tool | What Was Done |
|-------|------|---------------|
| 🧹 Data Cleaning & EDA | Python (Pandas) | Cleaned, transformed, and explored the dataset |
| 🔍 Data Analysis | SQL | Queried customer segments, loyalty, and purchase drivers |
| 📊 Visualization | Power BI | Built an interactive dashboard for business stakeholders |
| 📄 Reporting | PDF Report | Summarized findings and business recommendations |

---

## 🎯 Objectives

- Understand customer purchasing behaviour across demographics
- Identify top-selling products and categories
- Analyze seasonal and demographic trends
- Discover patterns in customer spending
- Provide actionable business recommendations

## 🔍 Analysis Workflow

### 1. 🧹 Data Cleaning & EDA (Python)
- Handled missing values and data type issues
- Explored distributions of age, gender, spending, and categories
- Identified outliers and trends using Pandas & visualizations

### 2. 🔍 SQL Analysis
- Extracted insights on customer segments and purchase drivers
- Queried top categories, high-value customers, and seasonal patterns
- Simulated business transaction analysis

### 3. 📊 Power BI Dashboard
- Built interactive dashboard with filters by category, season, and gender
- KPI cards for total revenue, average purchase, and customer count
- Visual charts for spending trends, demographic breakdowns, and top products

---

## 💡 Key Business Insights

- 📦 Certain product categories consistently outperform others in revenue
- 👥 Specific age and gender segments drive the majority of purchases
- 📅 Seasonal demand spikes observed — ideal for targeted campaigns
- 💳 Payment method preferences vary by customer segment
- 🔁 Loyal customers contribute disproportionately to total revenue

## ▶️ How to Run

### Python Notebook
```bash
# Clone the repo
git clone https://github.com/kartheek-r/Customer-Behaviour-Shopping-Trends-Analysis.git
cd Customer-Behaviour-Shopping-Trends-Analysis

# Install dependencies
pip install pandas matplotlib seaborn jupyter

# Launch notebook
jupyter notebook Customer_Shopping_Behavior_Analysis.ipynb
```

### SQL Queries
- Open `customer_behavior_sql_queries.sql` in any SQL editor (PostgreSQL / MySQL)
- Import the CSV dataset into your database
- Run the queries to explore business insights

### Power BI Dashboard
- Open `customer_behavior_dashboard.pbix` in **Power BI Desktop**
- Explore the interactive dashboard with filters and slicers
